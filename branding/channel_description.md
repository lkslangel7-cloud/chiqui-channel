# 채널 설명 (치키 타운 / Chiqui Town)

유튜브 스튜디오 → 맞춤설정 → 기본 정보 → 설명. 언어별 번역에 각각 붙여 넣는다.

## 한국어

```
치키치키 출발! 🦕
아기 트리케라톱스 치키와 공룡 마을 친구들이 노래하고 춤추는 치키 타운이에요.

🥚 숫자·색깔·감정 배우기 동요
🪥 양치, 손 씻기 같은 생활 습관 노래
🦖 바우 할아버지의 재미있는 공룡 상식

2~5세 아이들이 따라 부르기 쉽게, 짧고 반복되는 노래로 만들어요.
치키, 로로, 토롱, 피오, 바우 할아버지와 함께 신나게 놀아요!

새 노래를 놓치지 않으려면 구독해 주세요 🔔
```

## English

```
Chiqui Chiqui, let's go! 🦕
Welcome to Chiqui Town, where baby triceratops Chiqui and friends sing and dance in a colorful dinosaur village.

🥚 Sing-along songs for counting, colors and feelings
🪥 Healthy habit songs like brushing teeth and washing hands
🦖 Fun dinosaur facts with Grandpa Bau

Simple, repetitive songs made for toddlers and preschoolers (ages 2–5).
Come play with Chiqui, Roro, Torong, Pio and Grandpa Bau!

Subscribe so you never miss a new song 🔔
```
