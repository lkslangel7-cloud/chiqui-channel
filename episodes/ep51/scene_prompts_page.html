Higgsfield 웹사이트에서 장면 16개를 하나씩 만들어요. 장면마다 ①→②→③ 순서만 지키면 돼요.

📐 그림 화면에서 모델 이름 옆 「⛶ 자동」 버튼을 눌러 16:9로 바꾼 다음 만들어요. 다 만들면 공유 링크를 보내 주세요.

저장해 둔 친구들 (Elements)

Higgsfield에 이미 저장해 두었어요. 웹사이트 프롬프트 칸에 @를 치면 목록에 나와요.

@chiqui 치키@roro 로로@torong 토롱@pio 피오@bau 바우 할아버지🏝 @village 마을 (화풍 기준)

② 그림 만드는 법

  1. Higgsfield에서 Image를 누르고, 모델은 GPT Image 2.6 Sunburst(무제한)를 골라요.
  2. 프롬프트 아래 줄, 모델 이름 옆 「⛶ 자동」을 눌러 16:9로 바꿔요. (자동으로 두면 정사각형이 나와요!)
  3. 시트는 올리지 않아요! 친구들과 마을 그림은 Higgsfield에 Elements로 저장해 두었어요. 프롬프트 안에 @chiqui, @village 같은 이름이 들어 있어서 자동으로 들어가요.
  4. 그림 프롬프트 옆 복사를 누르고 붙여 넣어요.
  5. 붙여 넣은 뒤 @이름이 색깔 있는 칸(이름표)으로 바뀌었는지 봐요. 그냥 글자로 남아 있으면, 그 글자를 지우고 @를 직접 쳐서 목록에서 친구를 골라요. 그다음 Generate를 눌러요.
  6. 그림을 확인해요. 친구 모습이 시트와 같고, 똑같은 친구가 두 번 나오지 않고, 풍선 개수와 색이 맞으면 성공이에요. 이상하면 한 번 더 만들어요.

③ 영상 만드는 법

  1. Video를 누르고, 모델은 Seedance 2.5(무제한)를 골라요.
  2. Unlimited(무제한) 스위치를 켜요.
  3. 「레퍼런스 추가하기」를 눌러 그 장면에서 만든 그림을 넣어요. 첫 프레임(시작 프레임) 선택지가 있으면 골라요. 캐릭터 시트나 @요소는 넣지 않아요! 그림 한 장만 넣어요.
  4. 길이는 장면에 적힌 대로(5초 또는 10초), 종횡비 16:9, 프롬프트 아래 🔊 소리는 끔으로 바꿔요.
  5. 영상 프롬프트를 복사해서 붙여 넣고, 길이(5초 또는 10초)를 장면에 적힌 대로 맞춰요. 소리(Audio) 스위치가 있으면 꺼요. 화질은 1080p.
  6. Generate 버튼을 눌러요.

⚠️ Generate 버튼에 크레딧 숫자가 보이면 누르지 말고 멈춰요. 무제한이 안 켜진 거예요. 스위치를 다시 확인하거나 저한테 알려 주세요.

다 만들면

파일 이름을 바꾸거나 올릴 필요 없어요. 여기 채팅에 "다 만들었어"라고만 말해 주세요. 같은 계정이라 제가 가져와서 확인하고 노래·대사를 붙여 완성할게요. 목록에 없는 장면(오프닝, 노래 시작 부분 등)은 앞 화 영상을 다시 써서 안 만들어도 돼요.
