# 1화. 공룡알 하나 둘 셋 (약 3분)

- 주제: 1~5 숫자 세기, 친구와 함께 찾기, 공룡은 알에서 태어나요
- 출연: 치키, 로로, 토롱, 피오, 바우 할아버지 + 아기 공룡 다섯
- 대사·내레이션 19줄, 노래 약 2분 (오프닝 15초, 알 찾기 노래 약 60초, 엔딩 15초 + 배경 반주)
- 가사: `lyrics_ko.md` / 프롬프트: `prompts.md`
