# 1화 가사 (한국어)

괄호 안은 아이들이 따라 외치는 메아리. Suno 스타일 문구는 맨 아래.

## 오프닝 주제가 (매회 같음, 약 15초)

```
[Intro]
쿵쿵 쾅! 쿵쿵 쾅!

[Verse]
뿔이 셋 치키 (치키!)
크앙 크앙 로로 (로로!)
목이 쭈욱 토롱 (토롱!)
하늘 슝슝 피오 (피오!)
안경 쓴 바우 할아버지 (허허!)
공룡 마을 친구들
치키치키 출발!
```

## 알 찾기 노래 (1화 노래, 약 60초)

후렴은 시리즈형: 매회 `___ 어디 있니?` 자리만 바꾼다.

```
[Chorus]
쿵쿵 쾅! 쿵쿵 쾅!
공룡알 어디 있니? (어디 있니?)
친구들아 같이 가자
치키치키 출발!

[Verse 1]
바위 뒤에 동글동글
크앙! 로로가 찾았다
알이 하나, 알이 둘 (둘!)

[Verse 2]
나무 위에 동글동글
쭈욱~ 토롱이 찾았다
알이 둘, 알이 셋 (셋!)

[Verse 3]
언덕 위에 동글동글
슝~ 피오가 찾았다
알이 셋, 알이 넷 (넷!)

[Verse 4]
나뭇잎 밑 동글동글
짠! 치키가 찾았다
알이 넷, 알이 다섯 (다섯!)

[Chorus]
쿵쿵 쾅! 쿵쿵 쾅!
공룡알 다 찾았다 (찾았다!)
친구들아 고마워
치키치키 출발!
```

## 엔딩 주제가 (매회 같음, 약 15초)

```
[Ending]
오늘도 재밌었지? (응!)
바우 할아버지도 (허허!)
안녕! 바이바이! 아디오스!
내일 또 만나요, 크앙!
```

## Suno 스타일 문구

세 곡 모두 같은 문구를 쓰면 채널의 소리가 하나로 통일된다.

```
toddler sing-along nursery song, slow easy tempo 92 bpm, Korean lyrics, clear slow pronunciation, simple melody with small note range, call-and-response with short pauses for kids to echo, warm female lead with kids choir, ukulele, marimba, glockenspiel, soft handclaps, gentle dinosaur stomp drum, major key, cheerful and cozy
```

- 오프닝·엔딩은 길이를 15초 안팎으로, 알 찾기 노래는 60초 안팎으로 만든다.
- 영어·스페인어 가사는 같은 박자로 `lyrics_en.md`, `lyrics_es.md`에 따로 다듬는다 (아직 작성 전).
