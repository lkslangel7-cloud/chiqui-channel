# 7화. 사과야 어디 있니? — 하나부터 열까지 가사 (한국어)

오프닝·엔딩·배경음악은 1화 곡. 새 노래 1곡, 1~5화와 같은 후렴 틀·박자.

```
[Chorus]
쿵쿵 쾅! 쿵쿵 쾅!
사과야 어디 있니? (어디 있니?)
친구들아 같이 가자
치키치키 출발!

[Verse 1]
낮은 가지 동글동글
크앙! 로로가 땄어요
하나, 둘 (둘!)

[Verse 2]
높은 가지 동글동글
쭈욱~ 토롱이 땄어요
셋, 넷 (넷!)

[Verse 3]
꼭대기에 동글동글
슝~ 피오가 땄어요
다섯, 여섯 (여섯!)

[Verse 4]
폴짝 뛰어 동글동글
짠! 치키가 땄어요
일곱, 여덟 (여덟!)

[Chorus]
쿵쿵 쾅! 쿵쿵 쾅!
사과야 어디 있니? (어디 있니?)

[End]
```
