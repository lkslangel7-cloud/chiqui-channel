# 4화. 친구야 어디 있니? — 숨바꼭질 (약 3분)

- 주제: 숨바꼭질·까꿍 놀이, 크다/작다 (토롱은 커서 목이 보이고, 피오는 작아서 꽃 속에 쏙), 1~5 세기 복습
- 출연: 치키(술래), 로로, 토롱, 피오, 바우 할아버지
- 대사·내레이션 16줄 (1화 음성 3줄 재사용), 노래 약 2분 (오프닝·엔딩·배경음악은 1화 곡, 숨바꼭질 노래 약 60초)
- 숨는 곳 (웃음 포인트): 로로 바위 뒤 → **꼬리가 보여**, 토롱 나무 뒤 → **긴 목이 보여**, 피오 꽃 속 → 작아서 쏙 (살짝 엿봄), 바우 할아버지 작은 덤불 뒤 → **몸이 다 보여**
- 물건 없음 (색 규칙 해당 없음). 꽃은 피오가 쏙 들어갈 만큼 큰 분홍 꽃
- 바우 할아버지 코너: "커도 작아도, 다 좋은 친구!" (크다·작다 비교 뒤 한 줄)
- 가사: `lyrics_ko.md`
